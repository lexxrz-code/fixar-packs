# orlov-tools/vet — Ветеринарные услуги

Пак для площадки ФиксАР (agrigate.pro).

## Что делает

- Ведёт дело по этапам сделки, определённым в `vet.yaml` (сущности,
  сделки, документы, шаблоны дел).
- Держит ведомости в самом деле (умение `patient_card`).
- Исполнитель и заказчик работают на одних этапах; смена ролей описана
  в описании направления.

## Чего не делает

- Не делает того, что объявлено режимом `not_built` (в том числе «Принять экстренный вызов вместо врача»).
- Не выходит за границы из списка `never` агента: цену от себя не называет,
  оплату не проводит, записи за людей не ставит.

## Файлы

| файл | о чём |
|---|---|
| `pack.yaml` | манифест: рубрики, состав, права |
| `vet.yaml` | направление |
| `tests/scenarios.yaml` | «не сломано» |
| `evals/vet.yaml` | «делает, что обещано» |

## Как проверить

```bash
python3 tools/pack.py validate packs/orlov-tools/vet
python3 tools/pack.py build packs/orlov-tools/vet --out dist
```
