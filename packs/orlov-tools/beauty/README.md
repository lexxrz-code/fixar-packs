# orlov-tools/beauty — Индустрия красоты

Пак для площадки ФиксАР (agrigate.pro). Ведёт дела салонного бизнеса:
разовый визит, курс процедур, подарочный сертификат.

## Что делает

- Дело о визите идёт по этапам сделки: заявка, подбор услуги и времени,
  подтверждение записи, визит, приёмка работы, оплата.
- Держит сетку записи в самом деле, собирает согласие на процедуру
  со списком вопросов о противопоказаниях, ведёт курсы процедур
  и подарочные сертификаты с номиналами и сроками.
- Сущности: «визит», «услуга», «сертификат». Роли: мастер, салон,
  клиент — салон, сдавая кресло мастеру, сам становится заказчиком.

## Чего не делает

- Не записывает клиента в внешние календари салонов (умение
  `online_booking`, режим `not_built`).
- Не принимает оплату: касса и переводы проходят мимо площадки (умение
  `payment`, режим `not_built`).
- Не советует медицинские процедуры и назначения — их ведёт медицина.
- Не называет цену от себя: прайс считают салон или мастер.

## Файлы

| файл | о чём |
|---|---|
| `pack.yaml` | манифест: рубрики, состав, права, пределы |
| `beauty.yaml` | направление: сущности, сделки, шаблоны дел, агент |
| `tests/scenarios.yaml` | «не сломано» — заявки разного вида |
| `evals/beauty.yaml` | «делает, что обещано» — границы поведения |

## Как проверить

```bash
python3 tools/pack.py validate packs/orlov-tools/beauty
python3 tools/pack.py build packs/orlov-tools/beauty --out dist
```
