# orlov-tools/photo — Фото и видеосъёмка

Пак для площадки ФиксАР (agrigate.pro). Ведёт дела о съёмке на заказ:
разовая съёмка, проект под ключ, аренда студии, печать альбома.

## Что делает

- Дело о съёмке идёт по этапам сделки: заявка, бриф, смета и договор,
  съёмка, обработка, показ, передача материала и оплата.
- Помощник уточняет вид съёмки, дату, место и бюджет; собирает в деле
  тайминг съёмочного дня и список кадров; напоминает про акт
  приёма-передачи материала.
- Сущности: «съёмка», «локация», «материал». Роли: фотограф, видеограф,
  заказчик, студия, ретушёр — фотограф в аренде студии и заказе ретуши
  сам становится заказчиком.

## Чего не делает

- Не бронирует студию и не платит: бронь и оплата остаются за человеком
  (умение `studio_booking`, режим `not_built`).
- Не пересылает файлы съёмки: исходники и ретушь ходят облаком или
  носителем мимо площадки (умение `file_delivery`, режим `not_built`).
- Не называет цену от себя и не оценивает художественное качество кадров.
- Не организует события и поездки: это соседние направления площадки.

## Файлы

| файл | о чём |
|---|---|
| `pack.yaml` | манифест: рубрики, состав, права, пределы |
| `photo.yaml` | направление: сущности, сделки, шаблоны дел, агент |
| `tests/scenarios.yaml` | «не сломано» — заявки разного вида |
| `evals/photo.yaml` | «делает, что обещано» — границы поведения |

## Как проверить

```bash
python3 tools/pack.py check packs/orlov-tools/photo
python3 tools/pack.py validate packs/orlov-tools/photo
python3 tools/pack.py build packs/orlov-tools/photo --out dist
```

Перед публикацией замените `namespace` и `publisher` на выданные
площадкой — они закрепляются за изданием навсегда.
