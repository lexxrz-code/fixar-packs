# orlov-tools/fitness — Фитнес и персональные тренировки

Пак для площадки ФиксАР (agrigate.pro).

## Что делает

- Ведёт дело по этапам сделки, определённым в `fitness.yaml` (сущности,
  сделки, документы, шаблоны дел).
- Держит ведомости в самом деле (умение `measure_log`).
- Исполнитель и заказчик работают на одних этапах; смена ролей описана
  в описании направления.

## Чего не делает

- Не делает того, что объявлено режимом `not_built` (в том числе «Записать клиента в расписание студии»).
- Не выходит за границы из списка `never` агента: цену от себя не называет,
  оплату не проводит, записи за людей не ставит.

## Файлы

| файл | о чём |
|---|---|
| `pack.yaml` | манифест: рубрики, состав, права |
| `fitness.yaml` | направление |
| `tests/scenarios.yaml` | «не сломано» |
| `evals/fitness.yaml` | «делает, что обещано» |

## Как проверить

```bash
python3 tools/pack.py validate packs/orlov-tools/fitness
python3 tools/pack.py build packs/orlov-tools/fitness --out dist
```
