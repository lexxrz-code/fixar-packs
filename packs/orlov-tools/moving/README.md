# orlov-tools/moving — Переезды и грузоперевозки

Пак для площадки ФиксАР (agrigate.pro).

## Что делает

- Ведёт дело по этапам сделки, определённым в `moving.yaml` (сущности,
  сделки, документы, шаблоны дел).
- Держит ведомости в самом деле (умение `inventory_sheet`).
- Исполнитель и заказчик работают на одних этапах; смена ролей описана
  в описании направления.

## Чего не делает

- Не делает того, что объявлено режимом `not_built` (в том числе «Нанять грузчиков или машину самому»).
- Не выходит за границы из списка `never` агента: цену от себя не называет,
  оплату не проводит, записи за людей не ставит.

## Файлы

| файл | о чём |
|---|---|
| `pack.yaml` | манифест: рубрики, состав, права |
| `moving.yaml` | направление |
| `tests/scenarios.yaml` | «не сломано» |
| `evals/moving.yaml` | «делает, что обещано» |

## Как проверить

```bash
python3 tools/pack.py validate packs/orlov-tools/moving
python3 tools/pack.py build packs/orlov-tools/moving --out dist
```
